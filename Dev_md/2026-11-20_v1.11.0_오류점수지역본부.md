## 무엇을 · 왜

- 요청: 오류점수를 지역과 본부로 가르는 계산만. 지역은 신고인부호(신고번호 앞 5자리)로 — 실제 데이터 비교에서 이 방식만 팀 숫자와 맞음. 분모는 GN 포함 고정(관세청 총신고건에 GN 포함 — 인천만 빼면 차액이 울산으로 넘어감).
- 기획자 결정(권장안): ① 인천 분모 ERP → 요약 시트 → 직접 입력 ② 본부별 분모 = ERP 본부별(GN 포함), 건기본부 + 울산 ③ ERP 파일은 저장하지 않음 ④ 예전 지역 설정은 새 기본 표 + 예전 울산 부호.
