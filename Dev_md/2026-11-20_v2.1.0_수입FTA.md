# 2026-11-20 v2.1.0 — 수입 FTA 탭(ERP 수입FTA 파일)

## 무엇을 · 왜

- 요청: 매달 보내는 「FTA 수입 실적 보고」 메일의 표(당월 · 누적 × 부품센터 · 건기본부 · 엔진본부 · 총합계, 물자대 전체 · 협정국 수입 가능 · FTA · 절감액 · 비율)를 ERP 수입FTA 파일에서 그대로 만들기. 지금까지 수입FTA 파일은 「목록에만 보관」이었고, FTA 탭은 실적 파일의 물자대_FTA 열로 활용률만 보였다.
- 수입실적 파일과 같은 신고를 란 단위로 받은 자료라 수입실적 합계에 더하면 이중 집계 — 따로 둔다.

## 어떻게

- `js/customs.js`
  - `DATASETS.ftaImport` — 머리글 이름으로 열 짝짓기. 금액은 원화 (\)/(₩)/(￦)Taxable.Amt 만(($) 열은 excludeRaw). 판정 열 4개(Tariff Reductions · FTA N/A Code · N/A Reason · Column sequence number), `detectKind` 의 decisive 를 개수로 바꿔 수입실적과 가름.
  - `ftaImportReport(recs, { month, filePeriods, today, naNames })` — 수리일자 월, GN 늘 제외, 파일 이름 기간 밖 제외, Plant → 본부(공통 EXPORT_PLANT_HQ), FTA = F+4자 이상, 가능 = FTA + 04 미적용, 절감액 = Tariff Reductions, 비율 = FTA ÷ 가능. 당월 · 누적 · 월별 · 협정별 · 사후적용 대기(신고번호 단위 · 경과일수) · 미적용 사유별 · 제외 건수.
  - `ftaSnapshot` · `ftaCompare` · `eok` · `FTA_NA_NAMES`(설정에서 고침) · `FTA_AGREEMENTS` · `FTA_BASIS`.
- `js/filerules.js` — fta 묶음 + 수입이면 dataset ftaImport(확정본 월 귀속 B · EXPORT- 원본은 조회 모드), 수출FTA 는 계속 목록에만.
- `js/dash.js` · `dashboard.html` — 「수입 FTA」 탭(#fta-imp): 기준 표기 · 월 선택 · 당월/누적 표 · 메일용 표 복사(ClipboardItem text/html + text/plain, 안 되면 execCommand) · 확정 · 확정 대비 · 월별 막대+선 · 협정별 · 사후적용 대기 · 미적용 사유 · 제외 줄. 예전 활용률은 접힌 「참고」.
  - 시험 중 발견: FTA 파일의 11월 수리일자 행이 공통 조회 기간에 들어가 **수입 탭 기준월이 2026.10 → 2026.11 로 바뀜**. 공통 기간 · 본부/국가 조건 · 집계 엑셀에서 ftaImport 를 뺌. FTA 파일만 있을 때도 뷰 · 탭을 보이게(renderTab).
- `guide.html` 자료 표에 수입 FTA 줄. `tools/check-ftafile.mjs`.
