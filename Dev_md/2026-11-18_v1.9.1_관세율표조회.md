## 어떻게

- `js/tariff.js`(새 파일, customs.js 처럼 브라우저 `window.Tariff` · node `require`): `loadTariff` · `normHs` · `baseRate` · `ftaRate` · `tariffMeta` · `tariffMetaText`, 시험용 `setFetcher` · `reset`.
  - Promise 캐시 — 두 번째부터 같은 Promise. 실패하면 `{ ok:false, error:'관세율표를 불러오지 못했습니다' }` 로 끝나고 표는 비움(조회 null).
  - JSON 은 받은 객체를 그대로 메모리에 두고 `rates[hs][구분]` 으로만 찾음(배열 순회 없음). localStorage 안 씀.
  - HS: 숫자만 남겨 10자리일 때만. ERP 엑셀에서 숫자 칸으로 저장된 01~09류(앞 0 빠져 9자리)는 null — 추측하지 않음.
  - tariffMeta 의 hsCount 는 기준세율 표(ac) 것(11,326). 협정세율 표는 11,310.
- `dashboard.html`: `<script src="js/tariff.js">`, FTA 탭 위 `#tariff-meta`. `js/dash.js`: `showTariffMeta()` — 탭 클릭 · renderFta 에서 부름(한 번만). `css/dash.css`: `.tariff-meta`.
