# 2026-11-16 v1.5.0 — 같은 종류 여러 파일을 모두 더해 계산

## 무엇을 · 왜

- 문제: 「엑셀을 올리세요」에 같은 종류의 파일을 따로 올리면 나중 파일이 앞 파일을 대체해 한 파일분만 계산됨. 한 번에 함께 올려도 머리글이 조금 다르면(21열 · 19열) 한 파일만 남음.
- 원인: `js/dash.js` 의 상태가 종류 하나에 파일 하나(`state.sets[kind]`). `addFiles` 가 끝에서 그 자리를 새 파일로 바꾸고, 같은 묶음에서는 머리글이 똑같을 때만 이어 붙였음.
- 지시(기획자): 종류마다 파일 여러 개 · 모두 합쳐 집계 / 머리글이 달라도 파일마다 짝지어 합침 / 이름이 같으면 그 파일만 바꿈 / 기간이 겹치면 경고 / 파일마다 한 줄 + 「이 파일 빼기」 + 종류별 합계 줄 / 안내 문구 구분 / 화면 · 사용법 · 기획서 설명 / 예전 저장 자료.
- 기획자 결정(권장안): ① 못 찾은 열이 있는 파일이 섞이면 그 종류는 집계 보류 ② 환급 건수 열이 일부에만 → 파일마다 더하고 「건수 열의 합 + 행 수」 ③ FTA 열이 일부에만 → 계산하지 않고 알림 ④ 저장 용량을 넘으면 예전 저장본도 지움.

## 어떻게

- `js/customs.js`(규칙)
  - `fileKey` — 같은 파일인지는 시트 이름을 뺀 파일 이름(`name`, 예전 자료는 `file`).
  - `upsertFile(files, item)` → `{ files, action: 'added' | 'replaced', index }`. 바꿀 때 머리글이 같으면 고른 열(override) 이어받음.
  - `mergeFiles(kind, files)` — 파일마다 `mapColumns` · `normalize`, 레코드에 `file` 표시(환급 · 건수 열 없는 파일은 `countRow`). `ok` = 모든 파일이 필수 열을 다 찾음. `map` = 모든 파일에 있는 항목만, 일부에만 있는 선택 항목은 `partial`(map 에도 숨긴 속성으로 붙여 `refundStats` 가 봄). 건너뛴 줄 · 확인할 것에 파일 이름. `overlaps`.
  - `periodOverlaps` — 월 기간이 하나라도 겹치는 파일 쌍.
  - `migrateSaved` — 저장 자료 v1(종류마다 파일 하나) · v2(파일 목록) · 망가진 자료 → `{ sets: { kind: { files } } }`.
  - `refundCountBasis` · `refundCount` — 'mixed'(건수 열의 합 + 행 수).
  - `ftaStats` — 열 없음(available/hasSaving false)이면 일부 레코드에 값이 있어도 null. 파일 하나일 때는 그전과 같은 결과(열이 없으면 값도 없었음).
  - `exportBook` 안내 시트 — `data[k].files` 가 있으면 파일마다 한 줄 + 합계 줄.
  - `sampleRefundMonths()` — 가짜 환급 두 달치(2025.01 21열: 「환급구분」을 세 번째 · 「비고」를 끝에 / 2025.02 19열).
- `js/dash.js`(그리기)
  - `state.sets[k] = { files, m }`, `build` = `mergeFiles`, `ready` = `m.ok`. `putFile` · `dropFile` · 파일 단위 `changeKind`(옮기면 그 종류에 더함, 같은 이름이 있을 때만 확인창).
  - 올린 자료 표 — 파일 줄(`tr[data-kind][data-file]`) · 합계 줄(`tr[data-kind-sum]`), 열 확인 · 열 고르기 · 종류 바꾸기 · 빼기 모두 `data-i`(파일 순번).
  - `save` 는 v2 로 저장하고 실패하면 예전 저장본을 지운 뒤 알림 문구를 돌려줌 → 올리기 안내 뒤에 붙임.
- 문서: `dashboard.html`(안 되는 것 목록의 「실시간」 설명), `guide.html`, `docs/기획서.md` · `plan.html`, `README.md`.
- `tools/make-samples.mjs` — `samples/시험용/` 에 두 달치 파일. 예제 5종 파일은 바이트 그대로.

## 어떻게 확인했나
